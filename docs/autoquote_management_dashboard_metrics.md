# Management Dashboard Metrics

## Purpose
This metric library defines the KPIs that should be tracked later in the management dashboard.

## Core KPIs
- RFQs harvested
- RFQs qualified
- RFQs rejected
- Average margin
- Average profit
- Quotes generated
- Submission packages generated
- Win rate

## Supporting KPIs
- supplier coverage by category
- supplier coverage by province
- pricing confidence average
- stale pricing count
- blocked category count
- manual review count
- briefing-session count
- delivery complexity count
- evidence completeness score

## Metric Definitions

### RFQs Harvested
Count of RFQs discovered and recorded for review.

### RFQs Qualified
Count of RFQs that pass initial screening for deeper review.

### RFQs Rejected
Count of RFQs rejected or blocked during screening.

### Average Margin
Mean margin across selected opportunities.

### Average Profit
Mean estimated profit across selected opportunities.

### Quotes Generated
Count of quote outputs generated for operator review.

### Submission Packages Generated
Count of submission-ready packages prepared for manual handling.

### Win Rate
Percentage of submitted opportunities that were awarded.

## Dashboard Rules
- Track counts and rates separately.
- Keep raw totals visible for audit use.
- Avoid using metrics as punitive operator scoring.
- Tie metrics back to evidence and workflow state where possible.

## Display Guidance
- Use trend lines for change over time.
- Use category breakdowns for pricing intelligence.
- Use province breakdowns for coverage planning.
- Use confidence indicators for evidence quality.
