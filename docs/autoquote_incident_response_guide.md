# Incident Response Guide

## Purpose
This guide describes how to respond when a nonconformity, control issue, or document problem is found.

## Response Steps
1. Stop the affected action.
2. Capture what happened.
3. Record timestamps, file names, and screenshots if relevant.
4. Preserve evidence.
5. Notify the responsible operator or supervisor.
6. Escalate for investigation if workflow integrity may be affected.

## Incident Types
- blocked tender misclassification
- pricing evidence inconsistency
- missing proof documents
- package version mismatch
- unexpected workflow state
- suspected control bypass

## Output
Record:
- incident summary
- severity
- evidence retained
- operator response
- resolution owner
