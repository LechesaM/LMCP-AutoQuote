# Runtime SLA Monitoring

## Monitored Metrics

- RFQ processing latency
- Review completion time
- Queue wait time
- Source uptime
- Operator acknowledgement time
- Backup freshness
- Telemetry freshness

## States

- `healthy`
- `degraded`
- `failing`

## Governance

- SLA monitoring is advisory only.
- Breaches do not trigger autonomous remediation.
