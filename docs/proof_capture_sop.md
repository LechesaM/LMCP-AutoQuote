# Proof Capture SOP

## Prerequisites

- Submission review is marked review-ready
- Proof artifacts are available
- The workflow has not been refused

## Required Fields

- Portal name
- Submission reference
- Submitted-by operator
- Proof file or proof artifact reference

## Timing

- Capture proof only after the review-ready state is confirmed
- Capture proof promptly after the manual submission action

## Audit Proof Rules

- Proof capture must be auditable
- Proof capture must not silently bypass review
- Proof capture must not imply autonomous submission

## No Proof Without Review

Proof capture is prohibited unless the workflow is already review-ready.
