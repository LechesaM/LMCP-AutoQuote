# Submission Package Handbook

## Purpose
This handbook defines the manual review steps for assembling a submission package.

## Review Flow
1. Confirm the quotation is approved for package assembly.
2. Confirm all required forms and attachments are present.
3. Confirm the package matches the final internal quote.
4. Confirm naming, versioning, and file order.
5. Confirm proof documents are attached where required.
6. Confirm the package is ready for manual submission handling.

## Key Checks
- completeness
- document order
- pricing consistency
- proof capture
- sign-off status
- archiving readiness

## Output
Record:
- package identifier
- completeness status
- missing items
- final reviewer
- readiness status
