# LMCP Final Frontend Pack

Copy these files into your existing frontend:

- `src/App.jsx`
- `src/App.css`
- `src/index.css`
- `src/services/api.js`

Then run:

```bash
cd /Users/Shared/LMCP-AutoQuote-Server/lmcp-frontend
npm run dev
```

Optional API base override:

```bash
echo 'VITE_API_BASE_URL=http://localhost:8000' > .env
```
