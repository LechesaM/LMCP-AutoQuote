# Supervised-Live Operations

LMCP AutoQuote runs as a supervised-live procurement operations platform.

## Daily operations

- Monitor runtime metrics, operational health, source reliability, and queue lag.
- Review operator workload, queue ownership, and overdue items.
- Validate backup presence and restore simulation status.
- Review incidents and runtime alerts before start-of-day and before shutdown.

## Governance monitoring

- Manual approval remains mandatory.
- `review_ready` remains mandatory.
- Proof capture remains mandatory.
- Final submission remains manual-only.

## Operator workflows

- Operator actions remain explicit and auditable.
- Assignments, escalations, acknowledgements, and review completion are governed.
- No autonomous execution or silent workflow transitions are permitted.
