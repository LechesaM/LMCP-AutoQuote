# Submission Readiness Checklist

Use this checklist for every RFQ before it can be marked ready for submission.

## Checklist

### RFQ-001

- [x] All items extracted
- [x] Quantities verified
- [x] Delivery location verified
- [x] Supplier matched
- [x] Pricing verified
- [x] Margin verified
- [x] BOQ completed
- [x] Mandatory documents attached
- [x] Submission package generated
- [x] Human review completed

## Control Rules

- No RFQ skips a stage.
- Do not mark submission ready until every checkbox is complete.
- Record the reviewer and timestamp in the tracker or notes field.
- If any item is missing, record the failure in the failure log.
