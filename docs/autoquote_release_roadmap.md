# AutoQuote Release Roadmap

## Purpose
This roadmap defines future phases for controlled capability growth without implying immediate runtime change.

## Phase 1: Controlled Production Candidate
Goal:
- stabilize the current governed operating model

Exit criteria:
- documentation is complete
- review discipline is stable
- operator guidance is consistent

## Phase 2: Production Certified
Goal:
- harden the production candidate into a formally certified operating state

Exit criteria:
- governance artifacts are complete
- evidence handling is consistent
- operational exceptions are well documented

## Phase 3: Semi-Automated Submission
Goal:
- introduce bounded automation only where governance explicitly permits it

Exit criteria:
- manual approval remains required where needed
- audit trail is preserved
- operator override paths are defined

## Phase 4: Operator Approved Auto-Submission
Goal:
- move toward controlled submission automation only after formal approval

Exit criteria:
- explicit governance approval
- clear rollback path
- clear operator oversight
- clear evidence chain

## Roadmap Notes
- Phases are planning constructs.
- No phase is active unless explicitly approved.
- Certified workflow controls remain intact until each phase is separately authorized.
- Current operational milestone: Weekly Regression Run #2.
