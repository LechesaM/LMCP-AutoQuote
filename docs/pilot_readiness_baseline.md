# Pilot Readiness Baseline

## Purpose
This document summarizes the pilot readiness model for supervised real-world RFQ operations.

## Readiness Dimensions
- Pilot readiness score
- Workflow correctness score
- Persistence reliability score
- Operational reliability score
- Operator governance score
- Refusal handling score
- Recovery readiness score

## Interpretation
- The readiness report is informational only.
- It does not authorize autonomous execution.
- It does not replace operator judgment.
- It should be reviewed before and during any pilot run.

## Go/No-Go Guidance
- Go only when the pilot remains fully supervised and all checkpoints are human-confirmed.
- No-go if approvals, reviews, or proof capture are bypassed.
- No-go if any final submission automation appears.

## Operator Expectations
- Refuse ineligible RFQs.
- Review warnings and failures.
- Record sign-offs carefully.
- Escalate integrity or recovery issues promptly.
