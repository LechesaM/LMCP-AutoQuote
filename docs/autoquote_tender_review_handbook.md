# Tender Review Handbook

## Purpose
This handbook gives operators a concise tender screening procedure for LMCP AutoQuote.

## Review Flow
1. Confirm the tender is in scope.
2. Check the category against the category library.
3. Check whether the tender is supply-and-delivery aligned.
4. Check briefing-session and site-visit requirements.
5. Check submission method and deadline risk.
6. Check supplier and lead-time coverage.
7. Decide whether to continue, hold, or reject.

## Key Checks
- blocked categories
- delivery complexity
- compliance overhead
- province coverage
- evidence completeness
- expected margin potential

## Output
Record:
- review outcome
- key reason codes
- missing evidence
- follow-up action
- operator name and date
