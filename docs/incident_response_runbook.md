# Incident Response Runbook

## Incident types

- Parser outage
- Queue overload
- Auth outage
- Stale telemetry
- Deployment issue
- Runtime degradation
- Source failure cascade

## Response

- Record the incident.
- Acknowledge it explicitly.
- Contain the issue.
- Escalate to the appropriate operator or supervisor.
- Preserve auditability.

## Limits

- No autonomous remediation.
- No submission or workflow bypass.
