# Operator Dashboard SOP

## Purpose

The dashboard provides visibility and controlled operator assistance. It does not control the workflow autonomously.

## Queue Meanings

- Pending approval queue: RFQs waiting for approval review
- Review-ready queue: RFQs approved and waiting for review handling
- Proof-capture queue: RFQs ready for manual proof capture
- Refusal queue: RFQs that were blocked or rejected
- Archive queue: RFQs that have been archived

## Allowed Operator Actions

- Archive a refused or completed workflow
- Refuse a blocked RFQ
- Add operator notes
- Acknowledge warnings

## Prohibited Operator Actions

- Autonomous submission
- Bypassing approval or review
- Skipping workflow stages
- Mutating audit history
