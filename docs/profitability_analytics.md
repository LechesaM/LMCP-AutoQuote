# Profitability Analytics

LMCP profitability analytics estimate RFQ opportunity value and margin defensibility from runtime evidence.

## Estimation Model

- Estimated profit is heuristic.
- Margins are advisory.
- High-value RFQs are surfaced for review, not auto-approval.

## Stale Evidence

- Stale quote evidence reduces confidence.
- Supplier evidence gaps are tracked explicitly.
- Results are non-financial-advice only.
