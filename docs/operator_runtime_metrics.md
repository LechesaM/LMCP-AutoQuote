# Operator Runtime Metrics

Operational metrics help operators keep the supervised-live queue manageable.

## Tracked values

- RFQs reviewed per operator per day
- Average review time
- Escalation frequency
- Overdue review frequency
- Queue ownership distribution
- Alert acknowledgement frequency
- Review completion rate

## Usage

- Metrics are advisory.
- Capacity is constrained to 10 operators with 100 RFQs/day each.
- Review promotion must not exceed 1,000 RFQs/day.
