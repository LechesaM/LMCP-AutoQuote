# Submission Review SOP

## Review-Ready Definition

An RFQ is review-ready only after approval is recorded and the required submission artifacts are complete.

## Required Artifacts

- Quote pack
- Pricing schedule or equivalent pricing file
- RFQ source document
- Approval record

## Checks to Perform

- Confirm the quote pack exists
- Confirm the pricing schedule exists
- Confirm the RFQ source file exists
- Confirm the approval check passed
- Confirm `final_submission_attempted` remains false

## Refusal Criteria

- Missing approval
- Missing quote pack
- Missing source document
- Missing submission pack
- Any attempt to force final submission

## Governance Rule

Review readiness does not authorize final submission. It only permits the workflow to advance to the next human-controlled stage.
