# AutoQuote Pricing Intake Template

## Purpose
This template turns the pricing expansion plan into a repeatable capture format for advisory intelligence work.

## Use Case
Use this template when adding pricing evidence for the next wave of category expansion.

## Record Header
- category
- product name
- supplier name
- province
- quote reference
- quote date

## Evidence Capture
- unit price
- quoted total
- delivery assumptions
- pack size
- unit of measure
- validity period

## Validation
- lead time
- confidence rating
- source type
- notes on exclusions
- operator who verified it
- review date
