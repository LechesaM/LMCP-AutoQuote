# Known Operational Risks

## Risks
- Heuristic RFQ extraction can miss edge-case language
- Supplier evidence gaps can reduce pricing confidence
- Technical RFQ complexity increases manual-review load
- Physical and courier submissions require manual handling
- OCR and PDF extraction limitations can reduce evidence completeness
- Dependency warnings remain visible in the test environment
- Pilot values depend on real runtime data and attached evidence

## Risk Posture
- These risks are known and documented
- None of these risks authorize autonomous final submission
- Manual governance remains required
