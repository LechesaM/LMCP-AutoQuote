# Bulk Review Governance

## Permitted Bulk Actions
- Assign operator
- Acknowledge alert
- Mark evidence missing
- Archive already-reviewed stale items

## Prohibited Bulk Actions
- Bulk approval
- Bulk submission
- Any workflow bypass
- Any proof-capture bypass

## Audit Requirements
- Every affected RFQ is audited individually.
- Bulk actions require explicit confirmation.
- Supervisor or admin access is required for bulk routes.
