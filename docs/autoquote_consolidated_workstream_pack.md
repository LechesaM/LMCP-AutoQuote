# AutoQuote Consolidated Workstream Pack

## Purpose
This consolidated pack groups the non-runtime AutoQuote planning artifacts into one operator-friendly entry point.

## Boundary
- Documentation only.
- No certified workflow changes.
- No runtime behavior changes.
- No submission authority changes.

## Source Of Truth
The machine-readable bundle is generated from `frontend/command-centre/src/data/autoquoteLibraries.source.json`.
Refresh it with `npm run generate:autoquote-libraries` in `frontend/command-centre`.
Validate it with `npm run check:autoquote-libraries` in `frontend/command-centre`.
